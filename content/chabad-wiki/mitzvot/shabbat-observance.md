# Shabbat Observance — Inner Dimension

**Hebrew:** שְׁמִירַת שַׁבָּת

See [[holidays/shabbat|Shabbat]] for the full treatment.

## Additional Dimensions

### The 39 Categories of Work
The 39 *melachot* (prohibited labors on Shabbat) are derived from the labors used to build the Mishkan. This connection is not coincidental: the acts that built the physical Divine dwelling are suspended on Shabbat — because Shabbat itself *is* the Divine dwelling in time rather than space.

### *Melacha* vs. *Avodah*
The Torah uses both terms. *Melacha* refers to creative, intentional work that changes the world. Shabbat prohibits this not because rest is passive, but because on Shabbat the creation is *complete* — human "creative work" would be redundant. On Shabbat, one exists in the completeness of Divine creation rather than adding to it.
